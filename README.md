# upload.ai: AI video content generator
 
Upload a video and get ready-to-use **YouTube titles and descriptions** generated by AI from what is actually said in it.
 
The video is converted to audio **directly in the browser** with FFmpeg (WebAssembly), transcribed with **OpenAI Whisper**, and then sent to **GPT** together with a prompt template you choose or write yourself. The answer is **streamed** to the screen in real time.
 
> Built during NLW 14 (Next Level Week), a Rocketseat event.
> This is the **frontend**. The API lives in [upload-ai-api](https://github.com/vinigouvea16/upload-ai-api).

## How it works
 
```
Video (.mp4)
   │  FFmpeg WebAssembly, in the browser
   ▼
Audio (.mp3, 20 kbps)  ──►  POST /videos                    (stored by the API)
                            POST /videos/:id/transcription  (OpenAI Whisper)
                                    │
                                    ▼
Prompt template + transcription ──► POST /ai/complete       (GPT, streamed response)
                                    │
                                    ▼
                         Titles / description on screen
```
 
**Why convert in the browser?** A video file is large, while the audio track at 20 kbps is a small fraction of it. Converting on the client keeps the upload small and fast and avoids running FFmpeg on the server. Whisper only needs the audio anyway.
 
## Features
 
- Upload a video with a local preview
- Video-to-audio conversion in the browser with **FFmpeg WebAssembly**, loaded on demand
- Transcription with **OpenAI Whisper**, with an optional keyword prompt to improve accuracy
- Ready-made prompt templates (YouTube title, YouTube description), plus custom prompts using a `{transcription}` placeholder
- **Temperature** control to balance creativity and precision
- Responses **streamed** token by token with the Vercel AI SDK (`useCompletion`)
- Clear status for each step: converting, uploading, transcribing, done

## Running locally
 
You will need the [API](https://github.com/vinigouvea16/upload-ai-api) running first.
 
```bash
git clone https://github.com/vinigouvea16/nlw14-upload-ai
cd nlw14-upload-ai
pnpm install
```
 
Create a `.env` file pointing to the API:
 
```env
VITE_URL=http://localhost:3333
```
 
Start the app:
 
```bash
pnpm dev
```
